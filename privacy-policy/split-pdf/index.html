Política de privacidad

Dividir PDF / Split PDF
Última actualización: 28 de abril de 2026

Esta política de privacidad explica cómo la aplicación Dividir PDF, también publicada como Split PDF en otros idiomas, accede, utiliza, protege y comparte la información relacionada con el usuario.

Responsable de la aplicación

El responsable de la aplicación es Antonio Quintana. Para cualquier consulta relacionada con esta política de privacidad o con el tratamiento de datos, puedes contactar en: mail@afquintana.com.

Datos y archivos a los que accede la aplicación

Dividir PDF permite seleccionar documentos PDF del dispositivo para dividirlos en varios archivos. La aplicación accede únicamente a los archivos PDF y a las carpetas que el usuario selecciona de forma explícita mediante los selectores del sistema Android.

  • La aplicación no escanea el almacenamiento del dispositivo.
  • La aplicación no accede a archivos que el usuario no haya seleccionado.
  • Los PDFs se procesan localmente en el dispositivo.
  • Los PDFs seleccionados y generados no se suben a servidores del desarrollador.

Uso de carpetas y archivos generados

Cuando el usuario divide un PDF, puede elegir la carpeta donde guardar los archivos resultantes. La aplicación puede recordar la última carpeta seleccionada para facilitar futuros guardados. Esta información se guarda localmente en el dispositivo.

Datos recopilados automáticamente

La aplicación usa servicios de Firebase proporcionados por Google para mejorar la estabilidad y entender el uso general de la aplicación:

  • Firebase Crashlytics: recopila informes de errores, datos técnicos del dispositivo, versión de la aplicación, registros de fallos y otra información necesaria para diagnosticar problemas.
  • Firebase Analytics: recopila eventos de uso y datos técnicos agregados, como información del dispositivo, sistema operativo, país aproximado, interacciones dentro de la aplicación e identificadores de instancia de la app.

Estos datos se utilizan para analizar errores, mejorar el rendimiento, entender qué funciones se usan y mantener la calidad de la aplicación. No se utilizan para vender datos personales.

Compartición de datos con terceros

La aplicación no vende datos personales. Los datos técnicos recopilados por Firebase pueden ser procesados por Google como proveedor de servicios. El tratamiento de estos datos está sujeto a las políticas y condiciones de Google Firebase.

Cuando el usuario utiliza la función de compartir un PDF, el archivo se entrega a la aplicación externa que el usuario elija, como correo electrónico, mensajería o servicios de almacenamiento. Esa acción depende exclusivamente de la elección del usuario y del tratamiento de datos de la aplicación receptora.

Publicidad

La aplicación no muestra publicidad actualmente y no utiliza SDKs publicitarios. Si en el futuro se incorpora publicidad, esta política se actualizará antes de publicar una versión que incluya ese cambio.

Base legal y finalidad

El acceso a PDFs y carpetas se realiza para proporcionar la funcionalidad principal de la aplicación: dividir documentos PDF y guardar los resultados. Los datos técnicos de Firebase se usan para seguridad, diagnóstico, análisis de funcionamiento y mejora del servicio.

Conservación de datos

Los PDFs seleccionados y generados permanecen en el dispositivo del usuario o en la ubicación elegida por el usuario. El desarrollador no conserva copias de esos archivos.

Los datos técnicos recopilados por Firebase se conservan según las políticas de retención configuradas y aplicables de Firebase/Google. El usuario puede solicitar información o eliminación de datos asociados contactando con el desarrollador.

Seguridad

La aplicación limita el acceso a los archivos seleccionados por el usuario y utiliza los mecanismos de permisos y selectores de documentos del sistema Android. Los datos enviados a Firebase se transmiten mediante los mecanismos de seguridad proporcionados por Google.

Menores de edad

La aplicación no está dirigida específicamente a menores de 13 años y no solicita conscientemente datos personales de menores. Si crees que se ha tratado información de un menor de forma indebida, contacta con el desarrollador para revisar la situación.

Derechos del usuario

Dependiendo de tu país o región, puedes tener derechos de acceso, rectificación, eliminación, oposición o limitación sobre tus datos personales. Para ejercer estos derechos, contacta en: mail@afquintana.com.

Cambios en esta política

Esta política puede actualizarse para reflejar cambios en la aplicación, en los servicios utilizados o en los requisitos legales. La fecha de la última actualización se mostrará al inicio de esta página.

Contacto

Si tienes preguntas sobre esta política de privacidad, puedes contactar con el desarrollador en: mail@afquintana.com.
