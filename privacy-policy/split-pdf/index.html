The app is operated by Antonio Quintana. For any questions about this Privacy Policy or data handling, you can contact the developer at: mail@afquintana.com.

Files and Data Accessed by the App

Split PDF allows users to select PDF documents from their device and split them into multiple PDF files. The app only accesses PDF files and folders that the user explicitly selects through the Android system document and folder pickers.

  • The app does not scan the device storage.
  • The app does not access files that the user has not selected.
  • PDF files are processed locally on the user's device.
  • Selected and generated PDF files are not uploaded to the developer's servers.

Output Folders and Generated Files

When the user splits a PDF, the user can choose the folder where the generated files will be saved. The app may remember the last selected folder to make future saves easier. This preference is stored locally on the user's device.

Automatically Collected Data

The app uses Firebase services provided by Google to improve stability and understand general app usage:

  • Firebase Crashlytics: collects crash reports, technical device information, app version, crash logs, and related diagnostic data needed to identify and fix problems.
  • Firebase Analytics: collects usage events and aggregated technical information, such as device information, operating system, approximate country, app interactions, and app instance identifiers.

This data is used to analyze crashes, improve performance, understand feature usage, and maintain the quality of the app. It is not used to sell personal data.

Data Sharing with Third Parties

The app does not sell personal data. Technical data collected through Firebase may be processed by Google as a service provider. This processing is subject to Google's and Firebase's applicable terms and privacy practices.

When the user uses the share feature, the selected generated PDF file is sent to the external app chosen by the user, such as an email app, messaging app, or cloud storage app. That action is controlled by the user and is subject to the privacy practices of the receiving app.

Advertising

The app does not currently display advertising and does not use advertising SDKs. If advertising is added in the future, this Privacy Policy will be updated before publishing a version that includes that change.

Purpose of Data Use

Access to PDF files and folders is used to provide the core app functionality: splitting PDF documents and saving the resulting files. Firebase technical data is used for security, diagnostics, analytics, app stability, and service improvement.

Data Retention

Selected and generated PDF files remain on the user's device or in the folder chosen by the user. The developer does not keep copies of these files.

Technical data collected by Firebase is retained according to the applicable Firebase and Google retention settings and policies. Users may request information or deletion of data associated with them by contacting the developer.

Security

The app limits file access to files and folders selected by the user and relies on the Android system document picker and permission mechanisms. Data sent to Firebase is transmitted using the security mechanisms provided by Google.

Children's Privacy

The app is not specifically directed to children under the age of 13 and does not knowingly request personal data from children. If you believe that a child's information has been handled improperly, please contact the developer so the situation can be reviewed.
